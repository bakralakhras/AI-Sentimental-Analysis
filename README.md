# 📊 Sentimental Analysis on Amazon Food Reviews  

### 💡 Project Overview
This project leverages **Natural Language Processing (NLP)** techniques to perform **sentiment analysis** on Amazon Food Reviews. Using various tools and models, we aim to classify customer sentiments as **positive** or **negative**, gaining insights into customer opinions and improving understanding of product feedback.

---

## 🚀 Features
- **Data Analysis**: Comprehensive preprocessing and visualization of Amazon review data.
- **Sentiment Analysis Techniques**:
  - **VADER (Valence Aware Dictionary and Sentiment Reasoner)** for rule-based sentiment analysis.
  - **Roberta Pretrained Model** from Hugging Face for advanced deep-learning-based sentiment analysis.
  - **Hugging Face Pipeline** for seamless model integration and evaluation.
- **Comparative Study**: Analyze and compare the performance of rule-based and machine-learning models.
- **Interactive Insights**: Clear and visually appealing visualizations for better data interpretation.

---

## 🛠️ Tech Stack
- **Languages**: Python  
- **Libraries**:
  - **Pandas** and **NumPy**: Data manipulation and preprocessing.
  - **Matplotlib** and **Seaborn**: Data visualization.
  - **NLTK**: Natural Language Processing.
  - **Hugging Face Transformers**: Pretrained models for sentiment analysis.

---

## 📂 Project Workflow
1. **Step 0**: Import necessary libraries and explore the dataset.  
2. **Step 1**: Preprocess and clean the data, including handling missing values and removing unwanted text.  
3. **Step 2**: Perform sentiment analysis using:
   - VADER for rule-based classification.
   - Roberta for deep learning-based analysis.
   - Hugging Face's sentiment analysis pipeline.
4. **Step 3**: Visualize and compare results to determine the most effective technique.  

---

## 📊 Key Insights and Results
- **VADER**: Quick and effective for simple text sentiment analysis.  
- **Roberta**: More accurate for nuanced reviews, especially with complex language.  
- **Comparison**: Deep learning models outperformed rule-based approaches for large datasets with diverse reviews.  

---

## 📈 Visualizations
- Sentiment distributions using bar charts and histograms.  
- Accuracy comparison between VADER and Roberta.  
- Word clouds showcasing frequent positive and negative words.
